# Marketplace Analytics Frontend (Next.js)

## Setup
1) Copy `.env.example` to `.env`.
2) Set `NEXT_PUBLIC_API_BASE_URL` to the API base URL (include scheme and port).
3) Install and run:
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Pages
- `/vehicles` search vehicle listings
- `/parts` search part listings
- `/analytics` inventory and price trends
- `/auth/login`, `/auth/register`
- `/admin/ingest` admin-only ingestion
